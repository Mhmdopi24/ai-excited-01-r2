A giant orange-red octopus bursts out of a tiny white bathtub, one tentacle raised high in triumph holding a little yellow rubber duck, while a frozen arc of splashing water catches the golden light. Deep crimson and gold blaze against a dark ink-blue background, so the whole image hits with a jolt of energy at first sight and still reads clearly as one huge central shape at small sizes. The twist is the scale: a creature far too big for its bath, celebrating its escape with the smallest possible trophy.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The program copies `entry.png` into the output directory as `entry.png`. It is deterministic: every run writes the exact same bytes.
